# School Management System

## About the Project

The School Management System is a web-based application developed to manage school administration tasks, including student admissions, student records, teacher information, fee collection, and reports.

The application uses ASP.NET Web Forms and C# for application logic and Microsoft SQL Server for data storage.

## Features

- **Student Admission:** Collect and manage student admission applications.
- **Admission Approval:** Review pending applications and manage admission status.
- **Student Management:** Add, search, update, and delete student records.
- **Teacher Management:** Maintain teacher details, qualifications, allocated classes, and subjects.
- **Fee Management:** Record fee amounts, paid amounts, remaining balances, and payment details.
- **Dashboard:** Display pending applications and student and teacher counts.
- **Reports:** Generate student, teacher, admission, and fee reports.
- **Class Upgrade:** Manage student class progression.

## Technologies Used

- ASP.NET Web Forms
- C#
- Microsoft SQL Server
- HTML
- CSS
- Bootstrap
- JavaScript
- Crystal Reports
- .NET Framework 4.8

## Database

The application uses Microsoft SQL Server to store student, teacher, admission, and fee information.

A compatible database schema and connection configuration are required to run the application.

## Project Purpose

This project was developed to practice web application development, database connectivity, CRUD operations, and school administration workflows.
